# Agent guide

VS Code color themes generated from `@langchain/macaw-tokens`. See README.md for tasks.

- `themes/*.json` is generated. Never edit it by hand: change `src/` and run `mise run generate`.
- Map VS Code keys to Macaw **semantic** tokens (`--bg-*`, `--text-*`, `--border-*`, `--icon-*`, `--syntax-*`). Use primitives (`--red-600`) only where no semantic token fits, as in the ANSI tables.
- Macaw's dark mode inverts its primitive scales, and `--white`/`--black` swap. Check both variants after any mapping change.
- `docs/images/hero.png` is generated by `mise run screenshots` from `screenshots/workspace/`. Edit the sample project or `screenshots/`, never the image.
- `assets/icon.png` is generated by `mise run icon` from `assets/langchain-logomark.svg`.
- `src/generate.ts`, `screenshots/capture.ts` and `screenshots/render-icon.ts` are the only files with I/O. Everything else is pure; keep it that way.
- Install packages with `sfw pnpm ...`, never bare `pnpm add`.
- Before finishing: `mise run check && mise run test`.
